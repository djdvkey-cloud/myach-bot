# Мяч — футбольный бот

Telegram-бот для футбольного чата: еженедельный опрос, статистика, составы,
фактический состав игры, ввод результата и расчёт оплаты.

Работает постоянным процессом на Amvera (`python bot.py`, данные в `/data`).
Рабочий источник кода — git-репозиторий Amvera (`master`); этот GitHub-репозиторий —
резервная копия и история. Подробности, модель данных и порядок деплоя — в `HANDOFF.md`
и `CLAUDE.md`.

## Для игроков (общий чат)

- `/статистика` — таблица
- `/составы Иванов, Петров, ...` — разбить список на команды
- `/оплата N` — сколько переводить
- `/матч`, `/отменить` — запись и отмена игры

## Для администратора

Личный чат с ботом: `/menu` — панель (опрос, игроки, составы, фактический состав,
результат матча, оплата, статистика) и `/help` — подробная инструкция.
