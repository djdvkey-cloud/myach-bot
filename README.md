# Мяч — футбольный бот

Бот для записи статистики игр, составления команд и автоматических опросов на тренировку.

Работает бесплатно на GitHub Actions.

## Команды

- `/матч Иванов 2+1, Петров 0+3` — записать результаты игры  
  (гол = 2 очка, пас = 1 очко)
- `/статистика` — таблица игроков
- `/составы Иванов, Петров, ...` — разбить на команды по силе (змейкой)
- `/отменить` — убрать последнюю записанную игру
- `/переименовать Старое = Новое`
- `/обнулить да` — полностью очистить статистику
- `/id` — узнать ID чата и свой ID

## Автоматика

- Каждую **субботу в 12:00** (Екатеринбург) бот публикует опрос на ближайший понедельник.
- Варианты ответа: `+` и `-`.
